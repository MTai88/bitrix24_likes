# Bitrix24: лайки с эмоциями в кастомных компонентах инфоблоков

Компонент добавляет в пользовательские компоненты инфоблоков «Битрикс24» блок
лайков (реакций) в стиле живой ленты — точно такой же, как в стандартной
ленте новостей портала.

## О чём этот репозиторий

Проект демонстрирует, как встроить кнопку «Нравится» с набором эмоций
(👍 ❤️ 🔥 😢 👎 и т. д.) в произвольный список элементов инфоблока, который
формируется собственным компонентом.

Готовый пример — страница `/likes/` с компонентом
`/local/components/mtai/element.list`, который выводит элементы любого
инфоблока (по умолчанию `official_news` — достаточно указать его символьный
код API в параметре `IBLOCK_API_CODE`) и к каждой карточке подключает штатный
компонент Битрикса `bitrix:rating.vote` в шаблоне `like_react`.

## Для какой редакции предназначено

⚠️ **Только для «Битрикс24».**

Решение использует модули и компоненты, доступные в «Битрикс24»:

- `\Bitrix\Main\Engine\CurrentUser` — API текущего пользователя портала;
- `\CRatings` и `CRatingsComponentsMain::getRatingLikeMessage()` — API
  рейтингов и реакций живой ленты;
- `\Bitrix\Main\UI\Extension::load("ui.bootstrap4")` — стили, идущие в
  комплекте с порталом;
- встроенный шаблон компонента `bitrix:rating.vote` с идентификатором
  `like_react` — это шаблон, который применяется в ленте новостей
  «Битрикс24».

## Состав

- `local/components/mtai/element.list/` — кастомный компонент, который
  выбирает элементы инфоблока и готовит данные для блока реакций.
  - `class.php` — логика компонента: подключение ORM-сущности инфоблока
    через `IblockTable::compileEntity()` по параметру `IBLOCK_API_CODE`,
    постраничная навигация, сбор данных рейтинга через
    `CRatings::GetRatingVoteResult()` / `CRatings::getEntityRatingData()`
    и подготовка параметров `bitrix:rating.vote` для каждого элемента.
  - `.parameters.php` — параметры компонента: `IBLOCK_API_CODE`
    (символьный код API инфоблока) и `PAGE_SIZE`.
  - `lang/ru/` — языковые файлы (подписи параметров, сообщения об ошибках,
    строки шаблона).
  - `templates/.default/template.php` — вёрстка карточки на Bootstrap 4 и
    подключение `bitrix:rating.vote` шаблона `like_react`; шаблон только
    выводит заранее подготовленные данные.
- `likes/index.php` — публичная страница, подключающая компонент
  `mtai:element.list` (открывается по адресу `/likes/`).

## Как развернуть

1. Скопируйте каталог `local/components/mtai/element.list` в свой портал
   «Битрикс24» в `/local/components/mtai/element.list`.
2. Скопируйте каталог `likes` в корень сайта портала.
3. Убедитесь, что в системе установлен модуль `iblock` и в нём есть инфоблок
   с символьным кодом API `official_news` (либо передайте в компонент
   параметр `IBLOCK_API_CODE` с кодом нужного инфоблока — править код не
   требуется).
4. Откройте страницу `/likes/` на портале — под каждой карточкой
   появится кнопка «Нравится» с набором реакций живой ленты.

Если инфоблока нет, создайте его в административном разделе
(«Контент → Информационные блоки») и заполните поле «Символьный код API».

## Как устроен рейтинг

Для каждой карточки в компоненте формируется идентификатор голоса
`VOTE_ID = "IBLOCK_ELEMENT_" + ID` — именно его ожидает штатный
компонент рейтинга. Дальше `bitrix:rating.vote` сам хранит голос
текущего пользователя, считает суммарные `TOTAL_VOTES`,
`TOTAL_POSITIVE_VOTES`, `TOTAL_NEGATIVE_VOTES` и список реакций
(`REACTIONS_LIST`). Никакой собственной таблицы лайков проект не
создаёт — всё хранится в стандартных таблицах рейтингов Битрикса.
